# QSO Graph space weather

Parse NOAA Space Weather Prediction Center (SWPC) products from caller-supplied
bytes. The product formats and parser requirements are in
[Annex H](https://github.com/qso-graph/qso-graph-dxcluster/blob/main/spec/annex-h-space-weather.md).
