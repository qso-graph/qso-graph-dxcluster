# QSO Graph HTTP

Make synchronous HTTPS requests to configured providers and track their refresh
floors, retry delays, and backoff with a caller-supplied clock. See
[Annex I](https://github.com/qso-graph/qso-graph-dxcluster/blob/main/spec/annex-i-http.md)
for the client and scheduling requirements.
